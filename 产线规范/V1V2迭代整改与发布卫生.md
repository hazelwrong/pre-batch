# V1/V2 迭代整改与发布卫生

适用范围：后续 V0→V1、V1→V2 的整改主控指令、独立迭代会话和最终 release gate。已经冻结并提交终检的历史任务包不因本文自动回改；只有项目方明确要求重开时才重新进入整改。

## 1. 先分类，再决定是否整改

不得把正常的确定性 QA 当作 AI 生产痕迹。`pipeline`、`runner`、`validator`、`programmatic`、`deterministic`、`project_generated_validation`、`openpyxl` 等词仅表示构建、校验或文件处理工具时可以保留。没有明确的模型/Agent 生产披露或其他相互印证的证据时，不得据此建立“AI 痕迹” finding，也不得为了去除自动化表象而删除有效的当前字节验证。

以下内容不是 AI 生产的直接证据，但属于不得进入对外交付包的内部流程残留：`evaluator-term`、`evaluator-side`、`_shared_r4...`、`清理制作口径披露`、`对外交付采用中性业务表述`、`current_rebuilt_disclosure_cleaned_bytes`、`answer-artifact terminology`。内部整改前后记录、清理日志和工作底稿保留在任务根或主控工作区，必须位于 `delivery/` 外；`delivery/validation_evidence` 只保留最终版本、面向当前字节的状态验证。

真实的 `pending`、`not_run`、`stale` 人审或专家审状态不是 AI 问题，不得通过改字改成 `passed`。任何 final 或 release-ready 声明必须由真实完成的三层审核、当前最终字节的签署和哈希绑定支持。

manifest、inventory、provenance 中声明的每一个包内路径都必须实际存在。悬空路径是独立的 L3 完整性缺陷，与 AI 判断无关。

## 2. 主控整改分级

| 情形 | 默认路由 | 必做动作 |
|---|---|---|
| 清单、inventory 或 provenance 声明的路径不存在 | R1 | 修正路径或补齐真实文件；重生成所有依赖证据与哈希 |
| 单包含内部整改话术、清理日志或工作底稿 | R2 | 将内部记录移至 `delivery/` 外；仅用当前最终字节重建对外验证证据 |
| 同类问题由共享生成器批量产生 | R4 + 对应单包路由 | 修复模板/生成器；对全部同源任务包回扫；逐包重新运行受影响门禁 |
| 缺少真实人审、职业专家审或终审，却声称 final/release-ready | R3 | 停止文本修补；完成真实审核，对当前最终字节重新签署并绑定哈希；无法完成则保持未发布 |

整改会话的指令必须明确写出：问题类别、最早责任层、允许修改的文件、必须保持不变的真实材料、需要重建的证据、禁止伪造的状态，以及回传主控的校验结果。独立会话只向 V1/V2 迭代主控回传，不直接向甲方审核主控或专家发送材料。

## 3. 修改后的级联重建

任何正文、reference、Gold、Rubric、lineage、manifest 或验证证据发生变化后，按现有状态机从最早受影响节点回流，并依次完成：

1. 当前任务的内容与结构验证；
2. file inventory 与 provenance 重生成并逐路径核对存在性、字节数和 SHA-256；
3. security scans；
4. 当前版本 validation evidence；
5. final checksums；
6. 若变更触及已审核内容，按 change-impact 规则重新获得受影响层的真实复核与当前字节签署；
7. strict final validation、H-REG 和确定性双 ZIP。

不得沿用变更前的通过状态、签名、哈希或检查结果。

## 4. 最终 release gate

发布前除既有门禁外，必须同时满足：

- 对外交付树中不存在上述内部流程话术或内部清理工作底稿；
- 确定性 QA 证据仍完整、可复现，不因工具名称被误删；
- 不存在无真实审核支撑的 `passed`、final 或 release-ready 声明；
- tasks、manifest、inventory、provenance 声明的包内路径全部存在且绑定当前字节；
- 修改后的 validation、inventory/provenance、security scans 与 final checksums 均为当前状态；
- 三层真人审核、H-REG 和双 ZIP 条件满足既有 `policy.json` 发布不变量。

release gate 失败时保留诊断证据并停止打包，不通过文本替换规避门禁。
